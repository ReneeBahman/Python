# Pandas Basics (DataCamp Companion)

Companion notebooks for a DataCamp pandas course. I re-implement exercises locally in VS Code and track notes/takeaways.

## Structure
- `notebooks/` — Jupyter notebooks per lesson
- `scripts/` — any helper scripts
- `data/` — local data files (gitignored)
- `figures/` — plots exported from notebooks (gitignored)

## Environment
- Python via `.venv`
- Kernel: `Python (.venv) – pandas-basics`

## Quickstart
1. `python -m venv .venv`
2. `source .venv/Scripts/activate`  (Windows Git Bash)
3. `pip install -r requirements.txt` *(or install packages listed above)*
4. In a notebook, pick kernel **Python (.venv) – pandas-basics**.
